# 🪙 Thai Coin Counter & Detector
### ระบบตรวจจับและนับเหรียญไทย (Triple Engine: Local OpenCV, YOLO Offline AI, Roboflow Cloud)

ระบบตรวจจับภาพ (Computer Vision & Deep Learning) สำหรับนับจำนวนเหรียญและจำแนกประเภทเหรียญไทย (10 บาท, 5 บาท, 2 บาท, 1 บาท, สตางค์) ใช้งานได้ทั้งบนคอมพิวเตอร์และสมาร์ตโฟน รองรับ 3 รูปแบบการประมวลผล:

---

## 🌟 จุดเด่นระบบ 3 เอนจิน (Triple Engine)

1. **⚡ โหมด Local (OpenCV) - Offline 100%:**
   - ประมวลผลรวดเร็ว กินทรัพยากรน้อย เหมาะกับคอมพิวเตอร์ทั่วไป
   - ตรวจจับเฉพาะตอนมีเหรียญ ปฏิเสธพื้นหลังว่างเปล่า โต๊ะ หรือฝาขวดน้ำสีต่างๆ
   - จำแนกเหรียญ 10฿, 5฿, 1฿ พร้อมคำนวณเงินรวมแบบ Real-time

2. **🧠 โหมด YOLO (Offline AI) - Deep Learning ในเครื่อง ไม่ต้องต่อเน็ต:**
   - ใช้โมเดล YOLO Deep Learning (`models/thai_coins_yolo.pt`) ประมวลผลบนเครื่อง 100%
   - ตรวจจับเหรียญได้ 5 คลาส: `10฿`, `5฿`, `2฿`, `1฿`, `50สต.`
   - แม่นยำสูง แม้ถือกล้องเอียง เหรียญซ้อน หรือสภาพแสงเปลี่ยน
   - **ไม่ต้องใช้ API Key และไม่ต้องต่ออินเทอร์เน็ต**

3. **🌐 โหมด Roboflow AI (Cloud YOLO `sut-jpi3i/thai-coin-detection`):**
   - เชื่อมต่อโมเดล AI คุณภาพสูงจากมหาวิทยาลัยเทคโนโลยีสุรนารี (mAP@50 สูงถึง 99.4%)
   - ตรวจจับเหรียญได้ 7 คลาส: `10 Baht`, `5 Baht`, `2 Baht`, `1 Baht`, `.50 Satang`, `.25 Satang`, `Coin`
   - สามารถกรอก **Roboflow API Key** เพื่อเปิดใช้งานได้ทันทีจากเมนูตั้งค่า (⚙️) ในหน้าเว็บ

---

## 📱 ฟีเจอร์สำหรับการใช้งานบนมือถือ
* 🔄 **สลับกล้องหน้า-หลัง (Flip Camera):** แตะปุ่มเดียวเพื่อสลับมุมกล้อง
* 💡 **ไฟฉาย (Torch):** เปิดแฟลชมือถือเพื่อลดเงาและแสงสะท้อน
* 🎯 **ตรวจจับเฉพาะในกรอบเล็ง (Target Zone):** ตัดสิ่งรบกวนรอบห้องออกทั้งหมด
* 📸 **จับภาพนิ่ง (High-Res Snapshot):** ตรวจจับเหรียญจำนวนมากแบบคมชัด
* 🔔 **ระบบเสียงและสั่นเตือน (Haptics):** แจ้งเตือนเมื่อตรวจพบและนับเหรียญ
